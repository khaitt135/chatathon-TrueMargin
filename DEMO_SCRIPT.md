# True Margin — 5-Minute Demo Script

Practice this twice before 3:45 PM. Read it once more right before you go on.

---

### 0:00–0:30 — Problem

"Knowledge workers like Sarah spend their days in back-to-back meetings and
deadlines. She has no idea two weeks out that it's about to get bad.
Generic wellness apps tell her to 'protect focus time' — but her start
time is fixed, her meetings are fixed. She can't act on that advice.
True Margin works around what she can't change."

### 0:30–1:30 — Two-Week Dashboard

*[Open the app]*

"Here's Sarah's next two weeks — meetings and tasks. Most days look fine.
But Thursday the 25th is flagged. Let's see why."

*[Click the flagged day]*

### 1:30–2:30 — Why It's Flagged + Recommendation

"Thursday has three hours of high-focus work but only ninety minutes of
concentration-friendly open time. The math doesn't work. True Margin
suggests moving the Q3 analysis task to Wednesday, which has three free
hours."

*[Click Accept — watch the calendar update]*

### 2:30–3:30 — The AI Moment

"If Sarah needs help, asking without oversharing is hard. So we use AI for
exactly one thing: drafting an editable message."

*[Show the delegation mockup]*

"This is a static example for today's demo — in production it's AI-drafted
and always editable before sending."

### 3:30–4:00 — Close

"True Margin isn't a wellness diagnostic or a surveillance tool. It's a
two-week reality check on what's actually controllable — built to prevent
overload, not react to it."

### 4:00–5:00 — Q&A Buffer

Anticipated questions:

- **"How is this different from Clockwise or Reclaim?"** → *[insert your
  answer from Pre-Sprint Decision 1]*
- **"Is the delegation message really AI?"** → "It's a static mockup
  today; the production version calls the API live."
- **"Does the manager see check-in data?"** → "No — only the employee sees
  it. The manager sees task assignments only."
- **"What's actually built vs. simulated?"** → Point to the README's
  What's Working / Simulated / Planned sections.
